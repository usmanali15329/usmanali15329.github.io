Site Admin

Add blog posts, lab writeups, videos, and edit skills — committed straight to this repo via the GitHub API. No server, no database.

Before you paste a token here, read this:
  • Create a fine-grained personal access token scoped to only this repository, with Contents: Read and write permission and nothing else.
  • The token is kept only in this browser tab's sessionStorage — it is never written to any file, never committed, and disappears when you close the tab. Nobody else can use this page to edit your site; they'd need your token.
  • Don't paste your token in on a shared/public computer, and don't use a broad, all-repos token — a repo-scoped, contents-only token limits the damage if it ever leaks.
  • Every save here becomes a real, public commit to your repo (this is a public portfolio) — review the preview before saving.

Connected as .

New Blog Post

Configuration write-ups, how-tos, anything that isn't a HTB/THM box. Creates a file in _posts/.

New Lab Writeup

HackTheBox or TryHackMe walkthrough. Creates a file in _posts/ with category: htb or category: thm.

New Video

Creates a file in _videos/. Leave YouTube ID blank if the recording isn't uploaded yet — the page will show "Coming Soon" until you fill it in later.

Edit Core Skills

Raw YAML for _data/skills.yml — the categorized skill pills on /skills.html. (The "Skill Activity" bars below them are computed automatically from tags and aren't edited here.)

Browse & Edit Files

Jump straight to a folder, pick a file, edit its raw content (front matter included), and save. Useful for fixing a typo, filling in a youtube_id later, or editing _data/experience.yml.
